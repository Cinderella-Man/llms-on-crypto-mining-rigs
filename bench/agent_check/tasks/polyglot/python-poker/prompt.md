# Poker

# Instructions

Pick the best hand(s) from a list of poker hands.

See [Wikipedia][poker-hands] for an overview of poker hands.

[poker-hands]: https://en.wikipedia.org/wiki/List_of_poker_hands

---

Implement this exercise in `poker.py`, the stub in the current directory. Keep the names of the existing functions and
classes, since the tests import them. Use only the Python standard library; no packages can be installed.

`poker_test.py` holds some of the tests; run them with `pytest`. A hidden test suite with more cases will be run on
your solution when you finish.
