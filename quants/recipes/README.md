# Recipes

The exact `llama-quantize` options for each quant made in this subproject, so it can be rebuilt. Pass a recipe as
`EXTRA` to [scripts/quantize_docker.sh](../../scripts/quantize_docker.sh), with the base type and source named in the
table.

| Recipe | Source | Base type | Importance matrix | Notes |
|---|---|---|---|---|
| [flint-udmirror-v1.txt](flint-udmirror-v1.txt) | Flint Q8_0 (Unsloth) | Q4_1 | Unsloth's `imatrix_unsloth.gguf_file` | Unsloth UD-Q4_K_XL's per-tensor allocation with Q5_K→Q5_0, Q6_K→Q8_0, IQ4_XS/Q4_K/IQ3_S→Q4_1, Q8_0 kept; generated by [mirror_recipe.py](../../scripts/mirror_recipe.py) |

```bash
EXTRA="$(cat quants/recipes/flint-udmirror-v1.txt)" \
  scripts/quantize_docker.sh <llama.cpp source> <models folder> flint-Q8_0.gguf flint-udmirror-v1.gguf Q4_1 imatrix_unsloth.gguf
```
